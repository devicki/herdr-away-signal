# away-signal

[English](README.md) | [한국어](README.ko.md) | 日本語 | [繁體中文](README.zh-TW.md)

![away-signal: prefix+a でマシンを離席にすると、作業を終えたエージェントが Webhook ですぐボットに届きます](docs/away-signal.gif)

席を外すときのための [Herdr](https://herdr.dev) プラグインです。キーひとつで離席モードをオン・オフします。オンの間は、エージェントがターンを終えたときや入力を待っているときに Webhook へ POST します。そのため、マシンを見守るオーケストレーターは Herdr をポーリングせずにシグナルを受け取れます。

- **離席モード**: マシンごとにフラグファイルがひとつあります。キーでこのファイルをオン・オフし、新しい状態を Webhook へ POST し、Herdr にも表示します。
- **エージェントのシグナル**: 離席モードがオンの間だけ送ります。エージェントが入力を待っているとき（`blocked`）、またはターンを終えたとき（`working` の後に `done` か `idle`）です。その状態が 60 秒続く必要があり、送る直前に Herdr から状態を読み直します。そのため、ターン途中の一時停止が通知されることはありません。同じペインの同じ状態は 10 分以内に再送しません。
- **ドライラン**: Webhook の URL がない場合（または `dry_run = true` の場合）は何も送らず、すべてのシグナルをログに書き込みます。

Herdr 0.9.5 以降、bash、curl、jq が必要です。

## ボットのためのプラグイン

JSON の POST を受け取れるサービスなら、どれでもこのシグナルを受け取れます。ただ、このプラグインはひとつの目的のために作りました。ボットに離席シグナルを渡すことです。Grok Bot や dots のように、Herdr マシンを代わりに見守るチャットボットやエージェントオーケストレーターは、2 つのことを知る必要があります。あなたがキーボードの前にいるかどうか、そしてエージェントがいつ作業を終えたか、または行き詰まったかです。away-signal を使えば、SSH で Herdr をポーリングしなくても、この 2 つがボットに届きます。

1. 席を立つときにオンのキーを押します。ボットはあなたが離席したことを知り（`{"type":"away","on":true}`）、引き継げます。質問をスマートフォンへ転送したり、作業を続けたりできます。
2. 離席中は、ターンを終えたエージェントや入力を待つエージェントが、それぞれひとつのシグナルとして届きます。ペイン、エージェント、タイトル、フォルダーが含まれるので、ボットはどこを見ればよいかわかります。
3. 戻ったらオフのキーを押します。ボットは手を引きます。

離席モードはマシンごとに別々で、すべてのシグナルにどのマシンかが含まれます。そのためボットはマシンを 1 台ずつ別々に見守れます。たとえば、離れたマシンのエージェントはボットに任せ、別のマシンでは自分で作業を続けられます。複数のマシンをまとめてそろえたい場合は、ボットが SSH で[フラグファイル](#フラグファイル)を作成・削除します。

## Herdrbot

[Herdrbot](https://x.ai/bot/_919WifLAy2hWk7R7juy-) は、Herdr のエージェントを SSH で指揮する既製の Grok Bot です。このプラグインも、もともと Herdrbot のために作りました。

1. **追加する**: Grok Bot アプリで[リンク](https://x.ai/bot/_919WifLAy2hWk7R7juy-)から追加します。短いセットアップの会話が、1 問ずつ続きます。
2. **接続を許可する**: エージェントが動くアカウントごとに Herdr をインストールします。Herdrbot が自分の SSH 鍵を作り、公開鍵だけを見せるので、そのアカウントの `~/.ssh/authorized_keys` に追加します。パスワードや秘密鍵を求めることはありません。
3. **アカウントの登録**: Herdrbot が各アカウントを短いラベル付きの Herdr マシンとして登録し（`herdr machine add`）、30 分ごとの見回りと朝のまとめを設定します。
4. **仕事を任せる**: チャットで、何を作るか直すか、どのマシンとリポジトリかを伝えます。`hb-...` という名前のエージェントを起動し（または指定したエージェントを再利用し）、見守って結果を知らせます。承認の確認に代わりに答えることはなく、merge・デプロイ・強制 push・削除は必ず先に確認します。
5. **任意: このプラグイン**: Herdrbot に離席シグナルの設定を頼むと、"Herdr signal" という Webhook ルーチンを作ります。そのルーチンの Webhook URL と key を各マシンの `away-signal.conf`（`url`、`key`）に入れ、`machine` を Herdrbot がそのアカウントに使うラベルに合わせ、[キーバインド](#キーバインド)を追加してください。プラグインがなくても、Herdrbot は 30 分ごとの見回りで動きます。

## インストール

```sh
herdr plugin install devicki/herdr-away-signal --ref v0.4.0 --yes
```

`--ref` はリリースを固定します。設定ファイルのテンプレートは、エージェントの状態が最初に変わったときかキーを最初に押したとき、または次に Herdr サーバーが起動したときに書き出されます。

## 設定

プラグインの設定ディレクトリ（`herdr plugin config-dir devicki.away-signal`、通常は `~/.config/herdr/plugins/config/devicki.away-signal/`）にある `away-signal.conf` です。秘密の値を含むファイルなので、本人だけが読めるように作成されます。すべての設定は [`away-signal.conf.example`](away-signal.conf.example) にあります。

| キー | デフォルト | |
|---|---|---|
| `url` | なし | Webhook。ない場合はすべてのシグナルがドライラン |
| `key` | なし | `Authorization: Bearer <key>` として送信 |
| `dry_run` | `false` | `true` なら送信せずにログに記録 |
| `machine` | 短いホスト名 | すべてのシグナルでこのマシンを示す名前 |
| `sleep_hours` | なし | 例: `23:00-07:00`。寝ている間、離席モードを自動でオンにする（[下記](#就寝時間)） |
| `delay` | `60` | 送信前に状態が続く必要がある秒数 |
| `repeat` | `600` | 同じペインの同じ状態を再送するまでの秒数 |

リクエストはすべて `Content-Type: application/json` の POST です。

```json
{"type":"away","on":true,"machine":"laptop"}
{"type":"agent","machine":"laptop","pane_id":"w1:p2","agent":"claude","status":"blocked","title":"fix the login test","cwd":"/home/me/shop"}
```

`status` は `blocked`、`done`（見ていない間に終わったターン）、`idle`（見ている間に終わったターン）のいずれかです。`title` はペインのターミナルタイトルです。

## キーバインド

プラグインはキーを割り当てられないので、`~/.config/herdr/config.toml` に次を追加して `herdr server reload-config` を実行してください。

```toml
[[keys.command]]
key = "prefix+a"
type = "plugin_action"
command = "devicki.away-signal.on"
description = "離席モード オン"

[[keys.command]]
key = "prefix+shift+a"
type = "plugin_action"
command = "devicki.away-signal.off"
description = "離席モード オフ"
```

席を立つときのキーと戻ったときのキーを分けています。同じキーをもう一度押しても状態は変わらないので、フラグがずれたマシンが逆に切り替わることはありません。キーひとつで使いたい場合は `devicki.away-signal.toggle` もあります。どちらのキーも Herdr 0.9.5 のデフォルトでは使われていません。自分の設定ですでに使っている場合は、別のキーを選んでください。

## 就寝時間

```
sleep_hours = 23:00-07:00
```

就寝時間が始まると離席モードが自動でオンになり、ボットにもいつもどおり離席シグナルが届きます。就寝時間が終わるとオフに戻りますが、就寝時間がオンにした場合だけです。寝る前に自分でオンにした離席モードはオンのままです。その間にキーを押すと、次の開始か終了まではキーが優先されるので、遅くまで作業するためにオフにすれば、その夜はオフのままです。時刻はこのマシンのローカル時刻で、日付をまたいでもかまいません。マシンごとに設定します。プラグインはエージェントの状態が変わるたびに確認し、次の開始・終了時刻に合わせて起きる小さな待機プロセスをひとつ置いておきます。範囲を変えると 15 分以内に反映されます。

## サイドバーの表示

離席モードがオンの間は、マシンごとに先頭のワークスペース 1 行に `away` トークン（🌙 away）が付きます。マシンにつき 1 行なので、どのマシンが離席中かがひと目でわかります。トークンはサイドバーの行で使うまで表示されません。次は Herdr のデフォルトのワークスペース行にトークンを加えたものです。`~/.config/herdr/config.toml` に追加してください。

```toml
[ui.sidebar.spaces]
rows = [
  ["state_icon", "workspace", "$away"],
  ["branch", "git_status"],
]
```

すでに `rows` をカスタマイズしている場合は、好きな行に `"$away"` を加えてください。ノートパソコンからリモートのマシンに接続している場合、サイドバーはノートパソコン側が描くので、ノートパソコンの設定に入れてください。SSH でフラグを変えた場合は、次にエージェントの状態が変わったときに表示が追いつきます。

## フラグファイル

このファイルが存在する間、離席モードはオンです。

```
~/.local/state/herdr/plugins/devicki.away-signal/away
```

マシンとアカウントごとに別々にあります。複数をそろえるには、SSH などでファイルを直接作成・削除してください（`touch <パス>` または `rm -f <パス>`）。どのシェル（fish も含む）でも使え、このときは何も送信しません。プラグインは状態が変わるたびに、そして送信する直前にもう一度フラグを読みます。

シェルからは次のように使います。

```sh
bash away-signal.sh on | off | toggle   # キーと同じ: フラグ、Webhook、Herdr の通知
bash away-signal.sh status              # on または off
```

## ログ

`~/.local/state/herdr/plugins/devicki.away-signal/away-signal.log` には、すべてのシグナルが `sent`、`FAILED`、`dry-run` の印付きで残ります。失敗したときは curl のエラーも残ります。キーが書き込まれることはありません。最後の 500〜1,000 行を保持します。

## テスト

```sh
herdr plugin link .   # 上記のインストールの代わりに、クローンしたフォルダーから
./test.sh
```

隔離された Herdr（専用の HOME、このプラグインだけをリンク）と localhost の代わりの Webhook を起動し、トグルアクション、`pane.agent_status_changed` フック、遅延と再送のルール、リクエストヘッダー、ドライラン、設定ファイルのテンプレートを確認します。普段使っている Herdr サーバーには影響しません。

実際のボットでも最初から最後まで確認しました（Herdr 0.9.5、Linux）。離席の通知、ターンを終えたエージェント（`idle`）、Claude Code のフォルダー信頼確認で止まったエージェント（`blocked`）がすべて届き、後の 2 つは 60 秒の再確認を経てから届きました。

Webhook がまだないときに手動で確認するには、プラグインをリンクしてキーを押し、エージェントがターンを終える間ログを見てください。

```sh
tail -f ~/.local/state/herdr/plugins/devicki.away-signal/away-signal.log
```

試すときは `delay = 5` にしておくと、1 分待たずに済みます。
